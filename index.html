Rafha Job Search Worker

This is a private, single-user job-search assistant for its owner. It runs a Python worker on GitHub Actions and stores job-search state and reports in the owner's Google Drive.

With the owner's consent, it reads Gmail message metadata to flag possible employer replies for review. It does not send email or submit job applications. A separate read-only pilot reviews public job postings with an OpenAI model using selected career facts from the owner's job-search state.

The app is currently available only to its owner. It is not a public job-search service.
