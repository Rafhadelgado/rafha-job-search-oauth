Rafha Job Search Worker

Privacy policy

Effective October 25, 2026. This is a single-user application used by its owner for a private job search.

Google data accessed

The app requests Google Drive access limited to files it creates or opens for its job-search ledger and reports. It requests read-only Gmail access. The current Gmail workflow reads recent message headers to flag possible replies from tracked employers; it does not send mail or change messages.

How data is used and stored

The job-search ledger and run reports are stored in the owner's Google Drive. Google OAuth credentials and an OpenAI API key are stored as encrypted secrets in a private GitHub repository for the scheduled worker. Workflow logs contain run summaries and links to public job postings, not Gmail message bodies or credential values. The app does not sell Google user data or use it for advertising.

The current AI pilot sends selected career evidence from the Drive ledger and public job-posting text to OpenAI for a bounded, read-only match assessment. Gmail message content is not sent to OpenAI. The AI assessment is saved in a Drive report for the owner's review; it does not automatically apply or contact employers.

Access, retention, and control

Only the owner controls the Google account, Drive files, and private GitHub repository. The owner can stop the GitHub Actions workflow, delete its secrets and Drive reports, and revoke the app's Google access in Google Account settings. This app retains Drive reports until the owner deletes them. The app does not share Google user data with employers.

For privacy questions, use the support email shown on the app's Google consent screen.
